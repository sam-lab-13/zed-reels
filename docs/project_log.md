# Zed Reels: decisions so far (from chat, up to 2026-11-14)
**Format:** 9:16 football cartoon reels, 20-30 s, original caricatures (no real likeness copies, no fabricated crimes, no club or sponsor endorsement). Facts checked against 2+ sources. No music baked in (audio is added in Instagram). SFX CC0 or self-made, logged in assets/sfx/CREDITS.md.

**Reels made:** Carrick sacked v1-v3 (v3 approved; black patch under the arm from pass_raw, fix in the next walk). Football's week (d7c86c2; feedback: reused pitch, weak gags, too Premier League-heavy). The Wrong Esposito v1 (a4bec5e).

**Story rules:** setup, build, twist; a running gag; cover La Liga, Serie A, Ligue 1, Bundesliga and internationals; don't repeat MrBeast/Haaland, Sage, Bruno or Carrick. Each scene gets its own setting. Style references are a character on a plain background, never a finished frame.

**Motion:** every action is a drawn flipbook (HARK.md Motion plan, 5020e7e). Puppet for small gestures only. Walk = flip_pages.py, feet locked.

**Workflow:** the chat finalizes ideas; GitHub is the source of truth (scripts/, gags/, docs/). Drawings move to self-hosted open models (docs/open_source_pipeline.md). No video files in git.
